# DirectX11 Engine
This is a self-developed game engine built with DirectX 11, created as a learning project to gain hands-on experience with low-level graphics APIs and to better understand how game engines work under the hood. The goal is to develop technical depth in real-time rendering, C++, and engine architecture.
